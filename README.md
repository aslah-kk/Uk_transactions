# UK Transaction Analytics Dashboard

## 📊 Project Overview

<img width="1162" height="655" alt="Uk trasactions" src="https://github.com/user-attachments/assets/0f3408dc-3541-426b-8de2-9936e5fefbdb" />


The **UK Transaction Analytics Dashboard** is a Power BI project designed to analyze transaction data and identify patterns in customer activity, merchant performance, transaction values, and potential fraud risks.

This interactive dashboard helps users explore transaction trends, compare customer segments, analyze merchant categories, and understand transaction statuses.

## 🎯 Project Objectives

- Analyze transaction volume and transaction values.
- Understand customer behavior across different regions and segments.
- Compare merchant categories and sectors.
- Identify failed transactions and their reasons.
- Analyze transaction fees and payment channels.
- Monitor fraud flags and merchant risk indicators.
- Review customer KYC verification status.

## 📈 Dashboard Pages

### 1. Title Page
Provides the introduction and main entry point to the dashboard.

### 2. Executive Summary
Presents a high-level overview of transaction performance and important metrics.

### 3. Transactional Analysis
Analyzes transaction amounts, transaction types, payment channels, fees, dates, and transaction statuses.

### 4. Merchant Analysis
Explores merchant categories, business sectors, and merchant risk indicators.

### 5. Customer Analysis
Analyzes customers based on region, customer segments, age groups, and KYC verification status.

## 🔍 Key Analysis Areas

- Transaction Value (GBP)

- Merchant Category Analysis

## 🛠️ Tools & Technologies

- **Microsoft Power BI Desktop** – Data visualization and dashboard development
- **Data Modeling** – Organizing transaction and related dimension data
- **Interactive Visualizations** – Exploring transaction patterns and performance

## 🚀 How to Use

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open the `ukteam(1).pbix` file in Power BI Desktop.
4. Navigate through the dashboard pages.
5. Use available filters and visualizations to explore the data.
